# 使用指南

## 第一次授权

1. 安装 APK，打开“配置”页。选择对应 SIM，再调整通话、5G 与更多设置。
2. 保留默认开启的“激活后自动守护”，点击“应用并守护”。
3. 在连接面板打开系统无线调试设置。首次使用需要临时开启开发者选项并连接 Wi-Fi。
4. 选择使用配对码配对。可通过应用的配对通知输入代码，也可返回手动面板填写配对端口和六位代码。
5. 等应用显示“无线 ADB 已连接”，继续应用配置。配对端口与连接端口是两回事；手动输入时不要混用。
6. 守护启动后可关闭开发者选项总开关；开关状态不参与守护判断。

系统的已配对设备列表中，新记录应显示为 Pixel IMS。旧版本创建的目录路径名称不会自动改名；下次需要重新配对时可手动遗忘旧记录。

## 日常使用

状态页展示的是配置守护与最近的 IMS 检查结果，不是对基带实时聚合状态的保证。未知读取显示“状态未更新”。

正常守护不需要持续无线调试或持续 Wi-Fi 连接。建议允许应用在后台使用电池；这能改善存活条件，不能保证系统永不结束进程。划掉最近任务与系统应用信息中的“强行停止”不同。

## 修改配置

点击“修改配置”，暂停守护后在配置页编辑，再重新授权并应用。暂停或恢复默认时，Android 结束授权会话可能关闭应用；应用会尝试重新打开对应页面，如未自动返回可手动打开。

配置页保留上次选择。灰色或未显示的网络图标不等于配置选择被删除；请同时查看守护状态和配置检查结果。

## 恢复默认

在状态页选择“撤销配置并恢复默认”并确认。

- 会先停止自动补写，再清除临时运营商覆盖。
- 有效守护会话存在时直接使用当前授权。没有有效会话时会打开连接面板。
- 通话期间会等待通话结束，避免中途修改配置。
- 没有观察到系统配置变化确认时，只显示恢复请求已提交，不把它当成已验证完成。
- 已保存的偏好与配对密钥保留，方便以后再次应用。

## 重新启动授权

重启手机、强行停止、授权连接或守护进程终止后，重新打开开发者选项和无线调试，连接应用，再执行“应用并守护”。无需因此清除全部应用数据或删除所有配对设备。

## 网络业务取向（1.2.2 测试版）

守护运行后，在状态页每张 SIM 的卡片中选择“系统默认／语音取向／数据取向”。切换使用当前授权，无需重新配对；通话期间会等待。所选项会保留以供下次启动守护应用，订阅回读会单独显示实际读值。停止、修改配置或撤销会尝试恢复首次修改前的取向。详见 [测试说明](TEST_USAGE_CHOICES.md)。
