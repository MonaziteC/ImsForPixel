Pixel IMS 的体积优化版本。保留 Material 3 界面、系统动态配色、无线授权、完整自定义配置守护与撤销配置功能。

### 本版改动

- APK 从 v1.2.0 的约 30.19 MB 缩减到约 6.75 MB，减少约 77.6%。
- 启用 R8 与资源裁剪，移除未使用的旧 ADB 库、废弃查询工具、重复代码及无用资源。
- 保留无线配对、Instrumentation 和加密提供程序所需的裁剪规则，仍提供通用 APK。
- 修正 JVM 证书测试受测试环境加密提供程序顺序影响的问题。

用户已确认 1.2.1-rc1 在目标设备上功能正常并同意发布。正式版沿用该手机端实现，更新版本名与版本号；这不代表所有设备和固件均经过验证。

### 安装

下载附件中的 `pixel-ims-1.2.1.apk`，可直接覆盖 v1.2.0 或 1.2.1-rc1，无需卸载。安装后如授权会话已结束，请重新连接授权并执行“应用并守护”，等待就绪后再关闭开发者选项。

本版继续使用此前的**开发签名**以支持覆盖更新；源码不包含私钥。其他签名的自行构建 APK 无法直接覆盖这一安装。

### 验证与源码

37 项 JVM / Compose 测试通过，release Lint 零错误；关键 DEX 入口、签名与 APK 对齐检查通过。具体构建工具与验证边界见仓库文档。

附件提供 APK、对应源码 ZIP、完整 Git 历史包和 `SHA256SUMS`，可下载后校验。正式版本号为 1.2.1，versionCode 为 12。

守护仍依赖存活的授权会话。重启、强行停止或守护会话终止后需要重新授权；NR / 图标配置不会强制建立物理载波聚合，也不保证永久显示 5G+。
