Pixel IMS 的 Material 3 界面与完整配置守护版本，基于 svenuks/ImsForPixel，NR 参数参考 ryfineZ/carrier-ims-for-pixel。

### 本版内容

- 官方 Material 3 1.4.0，跟随系统动态配色与明暗模式。
- 状态 / 配置两页，按需展开连接授权面板，简化正常运行时的页面。
- 守护全部应用自定义 IMS / NR 配置；双 SIM 独立维护，默认激活后自动守护。
- 状态页可撤销配置并恢复运营商默认。有效授权会话存在时可直接使用它撤销。
- 修正正常守护显示成持续加载的问题；未知 IMS 状态不再误报成未注册。
- 新的无线 ADB 配对记录名称固定为 Pixel IMS。
- 移除“保持 SA”开关及对应策略写入。

### 安装

下载附件中的 `pixel-ims-1.2.0.apk`。与前几版测试 APK 使用相同签名，可覆盖安装。安装后重新连接授权并执行“应用并守护”，等待就绪后再关闭开发者选项。

### 运行范围

守护依赖存活的权限会话；重启、强行停止、守护进程或授权连接终止后，需要重新授权。NR / 图标配置不等于强制物理聚合或永久显示 5G+。恢复默认会清除对应 SIM 的临时覆盖层，也可能影响其他工具写入同一层的值。

本 APK 沿用此前测试版本的**开发签名**，以支持覆盖更新；源码不包含私钥。自行构建或使用另一签名的 APK 不能直接覆盖该安装。
